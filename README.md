# نظام إدارة المخازن والمبيعات والنواقص (POS & ERP Store Management)

نظام متكامل ومخصص لإدارة نقاط البيع (الكاشير)، دليل الأصناف والمخزون، متابعة وتوريد النواقص اليومية، أرشيف حركة وتغيرات الأسعار، دفتر حسابات الآجل والديون للعملاء، وحصر وتفقيط نقدية الدرج اليومية.

---

## 🌟 المميزات الرئيسية

1. **نقطة البيع الكاشير (POS):**
   - بيع بسعر القطاعي أو سعر الجملة مع إمكانية التبديل بضغطة زر.
   - دعم البحث السريع بالاسم أو الكود.
   - إمكانية إضافة صنف حر/يدوي للفاتورة.
   - احتساب الخصم وطرق الدفع (نقدي / آجل / فيزا).
   - معاينة وطباعة الفاتورة الفورية وحفظها في الأرشيف.

2. **دليل الأصناف والمخزون:**
   - إدارة كاملة للأصناف (إضافة، تعديل، حذف، تصنيف).
   - أسعار الجملة والقطاعي، أكواد الأصناف، والوحدات (كرتونه، بالتة، شكاره، علبة...).

3. **سجل وقوائم النواقص اليومية:**
   - تنظيم النواقص حسب التواريخ.
   - تعليم البضائع التي تم استلامها وتوريدها.
   - زر مخصص لنسخ قائمة النواقص بصيغة جاهزة للموردين عبر **WhatsApp**.

4. **سجل حركة وتغيرات الأسعار:**
   - تسجيل دفعات تعديل الأسعار وتوثيقها حسب التاريخ.
   - حساب فوري لفروق الأسعار القديمة والجديدة ونسبة التغير.

5. **دفتر حسابات الآجل والديون:**
   - كشف حساب لكل عميل.
   - تسجيل دفعات السداد والمستحقات والمسحوبات الآجلة.

6. **تفقيط وعد فئات النقدية (درج الكاشير):**
   - عد فئات الجنيه المصري (200، 100، 50، 20، 10، 5، 1، 0.5 ج.م).
   - مطابقة رصيد الدرج مع مبيعات اليوم وتحديد العجز أو الزيادة.

7. **النسخ الاحتياطي والأمان:**
   - تصدير واستيراد قاعدة البيانات بالكامل بصيغة JSON.
   - استرجاع بيانات المصنع الأولية بضغطة زر.

## 🚀 التشغيل المحلي (Local Development)

```bash

# تشغيل خادم التطوير
npm run dev
```
